# Agent Mimi

Version 5.0 "Quantum" — Full-Screen TUI

## Run

    python -m mimi           # TUI (default)
    python -m mimi --classic # classic menu

## TUI Keys

    ↑ ↓         navigate sidebar
    Enter       open editor for screen
    v           view latest record (modal)
    /           live search filter
    :           command palette
    T           cycle theme
    r           refresh data
    Esc         clear filter
    q           quit

## Themes

    midnight  sunset  forest

- Destructive ops need typed confirmation
